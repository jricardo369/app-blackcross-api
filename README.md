# WodApi

## Tecnología utilizada
```
*Java 1.8
*Maven
*Jersey (JAX-RS) para REST web services
*Tomcat 8.0 o 8.5
*Gson (JSON)
*JWT (jjwt) para autenticación
*Log4j para logging
*Apache POI para manejo de Excel
*Apache Tika para procesamiento de documentos
*iText para generación de PDFs
```

## Propósito del proyecto
Sistema de gestión de asistencia y usuarios para Blackcross. Una API REST que permite controlar la asistencia a clases, gestión de horarios, y operaciones relacionadas con usuarios y configuraciones del sistema.
